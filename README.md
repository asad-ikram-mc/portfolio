## Hi, I'm Asad

I build systems that collect and read what people do online, and I study what those numbers can and cannot tell us. It started in 2018 with SQL tutoring on Fiverr as a computer science student in Pakistan, and grew into nearly eight years of data engineering for teams and clients in the UK, Canada, Italy, Ireland, the UAE and the US.

<img src="assets/readme-journey.svg" alt="Journey from Lahore to research" width="100%">

| | |
|---|---|
| **Now** | Co-founder and CTO at **Artemis AI** (UK), Data Engineer at **M+C Saatchi Fluency** (London), data collection at **Fix.com** (Canada) |
| **Before** | **Dubizzle Labs**, Lahore: first competitor-analysis data architecture for six products across ten countries, 300+ crawlers running daily, promoted twice |
| **Education** | **Chevening Scholar 2024/25**, MSc Data Analytics with Distinction, University of Portsmouth · BS Computer Science, FAST-NUCES |
| **Research** | *Is the Platform Part of the Measurement?* with Dr Ella Haig ([arXiv:2610.16757](https://arxiv.org/abs/2610.16757), preprint) |
| **Giving back** | [web-scraping-guide.com](https://web-scraping-guide.com/), a free guide to web data collection, and mentoring students into freelance work |
